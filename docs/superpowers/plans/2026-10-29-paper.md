# Paper Drafting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draft the full article for *Reading in a Foreign Language* in `paper/` (Markdown, APA 7, sole author, first person), with every number traceable to the result CSVs and every reference verified, plus the materials for the blind second genre coder.

**Architecture:** Three small, tested tools support the writing:
- `paper/tools/numbers.py` generates `paper/numbers.md`, the single source of every figure the paper may quote.
- `paper/tools/check_numbers.py` lists any number in a draft that is not in `numbers.md`.
- `paper/tools/wordcount.py` counts main-text words per section.

`reanalysis/second_coder.py` draws the coder sample and computes κ. The sections are drafted one at a time, each followed by a short open-questions list for Greg.

**Tech Stack:** Markdown; Python 3.13 + pandas + scikit-learn (κ) + pytest for the tools.

**Spec:** `docs/superpowers/specs/2026-10-29-paper-design.md`

## Global Constraints

- **Voice and audience:** sole author, first person singular ("I"). Written for a broad audience of language educators.
- **Format:** APA 7th edition.
- **Length:** abstract at most 150 words; 5–7 keywords. Main text about 7,000 words, references about 1,300, total at most 8,500.
  - **Section targets:** introduction 900, background 1,300, method 1,800, results 1,500, discussion 1,300, conclusion 200.
- **Tables and figures:** main-text tables at most 5; figures at most 2, generated from the CSVs by a script in `paper/figures/`.
- **Numbers:** every number comes from `paper/numbers.md`, which is generated from `reanalysis/results/*.csv`. No number is typed from memory.
- **References:**
  - Each entry in `paper/references.md` carries an HTML comment `<!-- verified: <source checked> -->`.
  - Content claims about sources Claude cannot read in full are marked inline `[CHECK: content]`.
  - The audit's errors are corrected (Kintsch & Vipond 1979; Alderson 2000; Hu & Nation 2000; Carrell 1987 in *Reading in a Foreign Language*).
- **Blinding:** self-references and the repository link are written as `[Author, 2023]` / `[anonymised repository link]` placeholders, with the real values recorded in `paper/blinding.md`.
- **Framing (Greg's decisions):**
  - The exam is not formally tied to the books; the comparison rests on the public school's ethical responsibility to prepare candidates.
  - All Lyceum students take English in all three grades; the books were in use throughout 2010–2026; books and papers are publicly available.
  - Diaspora papers: "popularly believed to be easier".
  - The thesis is cited as the origin of the corpus and earlier analysis, not framed as a correction.
  - AI assistance is declared in the method and in a disclosure statement.
  - Texts, scripts and measures are public.
- **"Pre-specified"** means *fixed before the analysis reported here*. The paper says the concreteness and passives differences were seen in the author's earlier analysis of the original 13 exam texts, and treats the 13 added exam texts as a partial out-of-sample check.
- **Gaps:** no new analyses. A gap goes to Greg as an open question.

## Review Focus

1. A percentage or p-value written in a different format from `numbers.md` (".004" vs "0.004", "97.8%" vs "97.80") must still be matched, not falsely flagged or falsely passed. → Task 1 `test_check_numbers_normalises_formats`.
2. Numbers that aren't results (years, sample sizes, section numbers, word limits, citation years) must not flood the checker's report. → Task 1 `test_check_numbers_ignores_years_and_small_integers`.
3. Word counts must exclude tables, headings, HTML comments, `[CHECK]` markers and the reference list. Otherwise the 7,000 budget is meaningless. → Task 1 `test_wordcount_excludes_tables_comments_headings`.
4. The coder sample must be reproducible (seed 1), include both groups and every fine label in use, and contain no labels in the coder-facing file. → Task 2 `test_sample_stratified_and_blind`.
5. κ with a label one rater never uses must still compute; mismatched text lists between rater files must fail loudly. → Task 2 `test_kappa_handles_unused_label_and_rejects_mismatch`.

```python
def test_check_numbers_normalises_formats():
    nums = "- g = −1.15 [−1.85, −0.62]; p = .0001; BH p = .0004; coverage 97.86%"
    draft = "concreteness g = -1.15 (95% CI [-1.85, -0.62]), p = 0.0001, coverage 97.86"
    assert unmatched(draft, nums) == []

def test_check_numbers_flags_unknown_value():
    assert unmatched("g = 0.73", "- g = 0.72") == ["0.73"]

def test_check_numbers_ignores_years_and_small_integers():
    assert unmatched("In 2010, 27 texts and 26 exam texts; Nation (2006); n = 53", "") == []

def test_wordcount_excludes_tables_comments_headings():
```

### Task 2: Second-coder materials

**Files:**
- Create: `reanalysis/second_coder.py`, `reanalysis/tests/test_second_coder.py`, `paper/second-coder/instructions.md`, `paper/second-coder/sample.csv` (generated; `book,text` only), `paper/second-coder/texts/` (copies of the 20 sampled texts, `NN.txt`, anonymised order)

**Interfaces:**
- Produces:
  - `draw_sample(labels: DataFrame, n: int = 20, seed: int = 1) -> DataFrame`: every fine label in use gets at least one text, both groups appear, the rest is filled proportionally to group size; the returned rows are in random (seeded) order.
  - `kappa(a: DataFrame, b: DataFrame, column: str) -> float`: Cohen's κ (`sklearn.metrics.cohen_kappa_score`) on `column` (`coarse` or `fine`) after aligning on `book,text`; raises `ValueError` naming the texts if the two sets differ.
  - `main()`: writes `paper/second-coder/sample.csv`, the text copies and a key file `paper/second-coder/key.csv` (`NN,book,text`, not given to the coder).
- **Instructions:** the fine scheme, the dominant-purpose rule and examples taken from the spec, **without** any of the author's labels. Response format: `NN,fine,coarse,reason`.

```python
def test_sample_stratified_and_blind(labels53):           # fixture: the frozen data/genre_labels.csv
    S = draw_sample(labels53)
    m = labels53.merge(S, on=['book', 'text'])
    assert len(S) == 20 and set(m.fine) == set(labels53.fine)
    assert S.book.eq('Panhellenics').any() and (~S.book.eq('Panhellenics')).any()
    assert list(S.columns) == ['book', 'text'] and S.equals(draw_sample(labels53))

def test_kappa_handles_unused_label_and_rejects_mismatch():
    a = pd.DataFrame({'book': ['b'] * 4, 'text': list('wxyz'), 'coarse': ['narrative', 'narrative', 'non-narrative', 'non-narrative']})
    b = a.assign(coarse=['narrative', 'non-narrative', 'non-narrative', 'non-narrative'])
    assert 0 < kappa(a, b, 'coarse') < 1
    with pytest.raises(ValueError, match='z'):
        kappa(a, b[b.text != 'z'], 'coarse')
```
