# Phase 4 RQ2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Answer RQ2: which open measures separate exam from coursebook texts (cross-validated elastic net), and does genre account for the difference (Greg-confirmed genre labels, composition test, within-genre comparison, regression check).

**Architecture:** `separation.py` holds the nested-CV classifier, the permutation test and the selection frequencies. `genre.py` holds label loading and validation, the composition/Fisher test, the within-genre comparison and the regression check. `data/genre_labels.csv` carries Claude's proposals and Greg's confirmations. Both scripts read features through a shared `stats6.load_features()`.

**Tech Stack:** Python 3.13, scikit-learn 1.9.1, scipy, statsmodels, pandas, pytest.

**Spec:** `docs/superpowers/specs/2026-10-29-phase4-rq2-design.md`

## Global Constraints

- Run from `reanalysis/`; `pathlib`; outputs in `results/`; seed 1; TDD.
- Corpus: 27 coursebook and 26 exam texts (Phase 3 part 2 exclusions apply).
- **Features (21, fixed):** `cov5k, conc_tok, imag, fam, mtld, hdd, mlc, clauses_per_sent, mean_sent_len, passive_inc, np_inc, vp_inc, adjp_inc, pp_inc, neg_inc, gerund_inc, inf_inc, cwo_adj, sem_overlap, conn_inc, causal_inc`.
- **Model:** `make_pipeline(StandardScaler(), LogisticRegressionCV(Cs=np.logspace(-2, 2, 9), l1_ratios=[0.1, 0.5, 0.9], penalty='elasticnet', solver='saga', cv=StratifiedKFold(5, shuffle=True, random_state=1), scoring='neg_log_loss', max_iter=5000))`. The outer loop is `LeaveOneOut`. Exam = 1.
- **Permutations:** **200** (spec G2 allows 200 when 1,000 is too slow; one nested run takes about 55 s), run in parallel with joblib, each using `np.random.default_rng(1 + i)` for permutation `i`. p = (1 + #{perm AUC ≥ observed}) / (1 + 200).
- **Selection threshold:** 80% of outer folds.
- **Genre scheme:**
  - **Fine labels:** {fiction, personal, biography, informational, argumentative, speech, review, other}.
  - **Coarse mapping:** narrative = {fiction, personal, biography}; non-narrative = {informational, argumentative, speech, review}; `other` takes the `coarse` given in the row.
  - **Mixed texts:** labelled by dominant communicative purpose.
- **Genre analyses** (Tasks 5–6) run only when every row has `status == 'confirmed'`. The commit that sets the last label to confirmed is the **label freeze**.
- **Within-genre comparison:** measures `conc_tok`, `passive_inc`; non-narrative coursebook vs non-narrative exam; BH over the two; descriptive only if either side has n < 5.
- **Fisher's exact test:** `scipy.stats.fisher_exact` p, plus `scipy.stats.contingency.odds_ratio(table, kind='conditional')` with its exact 95% CI.
- Add `scikit-learn==1.9.1` to `requirements.txt`.

## Review Focus

1. A label file with a missing text, an extra text, an unknown fine label, or `other` without a coarse value must fail loudly, naming the row. → Task 3 `test_load_labels_validation_errors`.
2. Genre analyses must refuse to run while any label is still `proposed`. → Task 3 `test_load_labels_requires_confirmed`.
3. A genre × group table with a zero cell must still return a finite conditional odds-ratio CI bound and a valid Fisher p, without crashing. → Task 5 `test_fisher_zero_cell`.
4. The scaler must be fitted inside each training fold (no leakage): a feature that is constant in the training fold but not overall must not crash or leak. → Task 1 `test_nested_cv_no_leakage_constant_in_fold`.
5. Fewer than 5 non-narrative texts on either side must switch the within-genre rows to descriptive (p and BH NaN, flag set). → Task 5 `test_within_genre_small_group_descriptive`.

```python
def separable(n=20, p=5, seed=0):
    rng = np.random.default_rng(seed)
    y = np.r_[np.zeros(n), np.ones(n)]
    X = rng.normal(size=(2 * n, p)); X[:, 0] += 3 * y      # only feature 0 carries signal
    return X, y

def test_nested_cv_separable_data():
    X, y = separable()
    r = nested_cv(X, y)
    assert r['auc'] > 0.9 and r['accuracy'] > 0.8 and len(r['prob']) == 40
    assert r['selected'].shape == (40, 5) and r['selected'][:, 0].mean() >= 0.8

def test_nested_cv_no_leakage_constant_in_fold():
    X, y = separable(); X[0, 1] = 50.0     # feature 1 constant-ish except one row
    r = nested_cv(X, y)
    assert np.isfinite(r['prob']).all()

def test_final_fit_sign():
    X, y = separable()
    assert final_fit(X, y)['coef'][0] > 0

def test_design_uses_version_and_labels():
    F = pd.DataFrame({'book': ['English 1', 'English 1', 'Panhellenics'], 'text': ['u1', 'u1', '2010-06'],
                      'version': ['full', 'first360', 'full'], **{f: [1.0, 2.0, 3.0] for f in FEATURES}})
    X, y, ids = design(F, 'first360')
    assert X.shape == (2, 21) and list(y) == [0, 1] and X[0, 0] == 2.0
```

```python
@pytest.mark.parametrize('rows, msg', [
    ('English 1,u1,poem,narrative,x,confirmed\nPanhellenics,2010-06,informational,non-narrative,x,confirmed\n', 'u1'),
    ('English 1,u1,fiction,non-narrative,x,confirmed\nPanhellenics,2010-06,informational,non-narrative,x,confirmed\n', 'u1'),

def test_load_labels_validation_errors(tmp_path, rows, msg):
    p = tmp_path / 'g.csv'; p.write_text(HEAD + rows)

    p.write_text(HEAD + 'English 1,u1,fiction,narrative,x,proposed\n'
                        'Panhellenics,2010-06,informational,non-narrative,x,confirmed\n')
    with pytest.raises(ValueError, match='u1'):
        load_labels(p, TEXTS)
    assert len(load_labels(p, TEXTS, require_confirmed=False)) == 2
```

### Task 5: Genre analyses

**Files:** Modify `reanalysis/genre.py`, `reanalysis/tests/test_genre.py`

**Interfaces:**
- Consumes: `load_labels`, `stats6.load_features`, `stats5.compare`, the `stats6.comparisons` output (`results/difficulty_comparisons.csv`, for all-text g).

  - `composition(labels: DataFrame) -> DataFrame`: counts of fine × group (`school`/`exam`), plus totals.

  - `regression_check(F, labels) -> DataFrame`: per measure, the OLS `measure ~ exam` and `measure ~ exam + narrative` (full texts) group coefficient, its 95% CI, and `pct_change` = 100 × (adjusted − unadjusted) / unadjusted.
